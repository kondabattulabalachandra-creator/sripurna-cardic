# Self-hosted web fonts

This site bundles Latin-subset variable WOFF2 files and their SIL Open Font License texts. Font files are served locally by GitHub Pages; browsers do not need a third-party font CDN.

- **Manrope** (display/headings), designed by Mikhail Sharanda. Official specimen: https://fonts.google.com/specimen/Manrope. Variable Latin WOFF2: https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2. License source: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt.
- **Source Sans 3** (body/UI), designed by Paul D. Hunt. Official specimen: https://fonts.google.com/specimen/Source+Sans+3. Variable Latin WOFF2: https://fonts.gstatic.com/s/sourcesans3/v20/nwpStKy2OAdR1K-IwhWudF-R3w8aZQ.woff2. License source: https://raw.githubusercontent.com/google/fonts/main/ofl/sourcesans3/OFL.txt.

The type pairing separates a crisp contemporary display voice from a highly legible humanist text face. Font weights are variable; display uses 600–750 and long-form text uses 400–500.
